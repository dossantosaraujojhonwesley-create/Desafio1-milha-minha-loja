# Elite Mobile — Simulador de Compras

## Informações do projeto

- **Aluno:** JHON WESLEY DOS SANTOS ARAUJO
- **Trilha:** DESENVOLVIMENTO MOBILE
- **Desafio:** Desafio 1 — Minha Loja

## Apresentação

A Elite Mobile é uma loja fictícia especializada em smartphones
premium. O projeto foi desenvolvido para praticar HTML, CSS
e JavaScript.

## Produtos

| Produto | Preço ilustrativo |
|---|---:|
| Samsung Galaxy S26 Ultra | R$ 10.999,00 |
| REDMAGIC Gaming | R$ 7.499,00 |
| iPhone 17 Pro Max | R$ 10.499,00 |

Compras a partir de R$ 10.000,00 recebem 10% de desconto.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.
4. Clique em "Simular compra".
5. Informe as quantidades e confira o resultado.
